# 交付恢复与前端实现

- 将下载目录的 44 个文件按 package、导入和架构恢复路径；保留交付目录原件。
- 保持 Go 1.24.7 最低版本，选择兼容 SQLite 驱动并锁定依赖；验证两个 Store 的契约、race 和迁移幂等。
- 前端采用灰蓝背景、白色消息区与蓝色操作色，左侧会话列表、右侧对话和底部输入。移动端列表收起。
- 会话组件按 ID / 历史版本挂载，直接 useReducer(applyEvent, …) 消费 SSE。初始 running 取详情；别处启动的任务轮询至结束后重新加载历史。
- 支持会话增删改、Markdown、折叠 reasoning、工具参数/状态/结果、插话/排队/停止。编辑先 setHead(parent_id)，重新加载后发送。
- 异步操作显示错误，防重复提交，流结束异常时恢复历史；不暴露 Token。
- 用 SQLite + 本地假模型验证真实 BFF/SSE/落库及浏览器操作；不请求真实模型。
